# Portefólio de João Santos

Repositório público organizado em duas áreas: projetos académicos e projetos
pessoais. Cada projeto tem a sua própria pasta e começa por um `README.md` com
o contexto, os artefactos disponíveis e as respetivas limitações.

## Navegação

| Área | Conteúdo |
|---|---|
| [Projetos Académicos](<Projetos Académicos/>) | Dez projetos académicos e curriculares em versões públicas curadas |
| [Projetos Pessoais](<Projetos Pessoais/>) | Projetos individuais, incluindo o código do site pessoal |

O site pessoal está publicado em
[joao-santos-biomedica.joaprs.chatgpt.site](https://joao-santos-biomedica.joaprs.chatgpt.site)
e o respetivo código encontra-se em
[`Projetos Pessoais/Site Pessoal/`](<Projetos Pessoais/Site Pessoal/>).

## Política de publicação

Este repositório contém apenas seleções preparadas para consulta pública. As
fontes de trabalho, credenciais, dados privados e materiais expressamente
excluídos permanecem fora do repositório. A visibilidade pública não concede,
por si só, autorização para reutilizar ou redistribuir os conteúdos.
