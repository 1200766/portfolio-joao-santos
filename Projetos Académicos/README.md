# Projetos Académicos

[← Voltar ao portefólio](../README.md)

Seleção curada de projetos académicos e curriculares de Engenharia Biomédica.
Cada pasta contém o respetivo README, os artefactos autorizados e as instruções
próprias do projeto. Os arquivos de trabalho e os dados privados permanecem
fora do repositório; os relatórios expressamente autorizados estão identificados
nos respetivos projetos.

## Projetos

| Projeto | Conteúdo público |
|---|---|
| [Biomecânica](biomecanica/) | Análise exploratória do perfil de marcha; resultados agregados, sem dados dos participantes |
| [MediBrain](medibrain/) | Comparação de estratégias automáticas de pré-processamento de EEG; código, instruções e relatório autorizado |
| [Interação Homem–Máquina](interacao-homem-maquina/) | Prova de conceito de análise de marcha *marker-free*; vídeos excluídos |
| [Sistema de Apoio à Decisão para Diagnóstico do Cancro da Próstata](<Sistema de Apoio à Decisão para Diagnóstico do Cancro da Próstata/>) | Projeto de Informática Médica; código histórico de frontend e backend, com diferenças face à versão final documentadas, e relatório original autorizado |
| [Plathink](plathink/) | Subsistema Arduino de um protótipo de monitorização alimentar |
| [PrediPE](predipe/) | Revisão conceptual e protótipo de apoio à decisão para pré-eclâmpsia com dados sintéticos |
| [PIMED/ATLAS](pimed-atlas/) | Reconstrução técnica individual para análise geométrica de vasculatura, com exemplos sintéticos |
| [SDSI — Trabalho 1](sdsi-trabalho-1/) | Vulnerabilidades Web/DICOM e demonstrações Java sanitizadas |
| [SDSI — Trabalho 2](sdsi-trabalho-2/) | Exercício académico sobre segurança e conformidade hospitalar |
| [SafeHealth](safehealth/) | Protótipo académico de telemonitorização com firmware e portal de demonstração |

## Como consultar

Abra uma pasta e comece pelo respetivo `README.md`. Dependências, comandos,
autoria, direitos e limitações são específicos de cada projeto.
