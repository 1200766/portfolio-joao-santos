# Dados locais

Esta pasta deve permanecer sem dados no Git.

Para obter apenas os exemplos públicos utilizados pelas pipelines curadas:

```bash
python scripts/download_siena_pn00.py PN00-1 PN00-2 PN00-4
```

Os ficheiros são descarregados diretamente da Siena Scalp EEG Database no
PhysioNet. Não coloque aqui dados de contexto clínico, dados recebidos durante o
estágio ou registos cuja proveniência e autorização não estejam documentadas.
